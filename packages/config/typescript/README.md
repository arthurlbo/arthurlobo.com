# `@repo/typescript`

Shared Typescript configuration package for the monorepo.

## Overview

This package provides a centralized Typescript configuration for all apps in the monorepo, ensuring consistent coding standards and compiler options across the workspace.

### Installation

This package is already part of the workspace. To use it in your app:

```json
{
    "devDependencies": {
        "@repo/typescript": "workspace:*"
    }
}
```
